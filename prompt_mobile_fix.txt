styles.css ve components.jsx dosyalarında şu 3 sorunu düzelt:

1. ProfileCard — "DÜZENLE" ve "ROZETLER" butonları birbirine giriyor:
styles.css'te mobile'da (.profile-actions veya butonların bulunduğu container):
@media (max-width: 767px) {
  .profile-actions {
    flex-direction: column;
    gap: 8px;
  }
  .profile-actions button {
    width: 100%;
  }
}
Eğer class adı farklıysa ProfileCard'daki buton container'ını bul ve düzelt.

2. Öğrenme Odak Alanları filtre chips (Tümü/Sayısal/Sözel/Dil) ekrana sığmıyor:
styles.css'te .section-title veya filter chips container'ına:
@media (max-width: 767px) {
  .section-title {
    flex-wrap: wrap;
    gap: 8px;
  }
  .section-title .right {
    width: 100%;
    flex-wrap: wrap;
  }
}

3. Alt navigation bar — Dersler ve Profil butonları sahte:
components.jsx'teki BottomNav veya bottom-nav component'ini bul.
Dersler butonuna: onClick={() => { setActive('subjects'); window.scrollTo(0,0) }}
Profil butonuna: onClick={() => navigate('/profile')} 
(react-router-dom'un useNavigate hook'u kullan)
Düello butonuna: onClick={() => navigate('/duel')}
Ana Sayfa butonuna: onClick={() => { navigate('/'); setActive('home') }}

Sadece bu 3 değişikliği yap, başka hiçbir şeye dokunma.
