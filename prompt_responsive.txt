Görev: Educai frontend'ini mobil responsive yap.

Mevcut layout: 3 sütun (sidebar + main + rail) — masaüstü için.
Hedef breakpoint'ler:
- Mobile: < 768px → tek sütun
- Tablet: 768px-1024px → 2 sütun (sidebar gizli, hamburger menü)
- Desktop: > 1024px → mevcut 3 sütun korunsun

styles.css dosyasına şu değişiklikleri ekle (mevcut kurallara dokunma):

1. Mobile (max-width: 767px):
   - .shell: flex-direction: column
   - .sidebar: gizle (display: none)
   - .rail: genişlik %100, flex-direction: row, wrap
   - .main: padding azalt (16px)
   - .subjects grid: 2 sütun (şu an 3)
   - ProfileCard: daha kompakt
   - Topbar: sadece isim + streak göster

2. Tablet (768px - 1024px):
   - .sidebar: gizle, hamburger menü ikonu göster
   - .main + .rail: yan yana, %60 + %40
   - .subjects grid: 2 sütun

3. Hamburger menü (mobile + tablet):
   components.jsx'e HamburgerMenu component'i ekle:
   - Sol üstte ☰ ikonu
   - Tıklayınca sidebar overlay olarak açılsın
   - Dışarı tıklayınca kapansın
   - Mevcut Sidebar component'ini kullan

4. Mobile'da alt navigation bar ekle:
   - Sayfanın altında sabit bar
   - 4 ikon: 🏠 Ana Sayfa, 📚 Dersler, ⚔️ Düello, 👤 Profil
   - Aktif olan highlight olsun
   - styles.css'e .bottom-nav class'ı ekle

Kurallar:
- Mevcut hiçbir desktop stilini bozma
- Sadece media query'ler ve yeni class'lar ekle
- TypeScript değil JSX kullan
- Mevcut tasarım diline uy (renkler, borderlar vs.)
