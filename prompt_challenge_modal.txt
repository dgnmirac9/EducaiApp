Görev: ChallengesCard'daki "Katıl" butonuna challenge detay modalı ekle.

components.jsx dosyasında:

1. ChallengeModal component'i oluştur:
   - Fixed overlay: bg-black/60, backdrop-blur-sm, z-index: 1000
   - Merkezi modal kart: glass efekti, max-w-md, rounded-2xl, p-6
   - İçerik:
     * Üst: Challenge başlığı + X kapatma butonu
     * Rozet/ikon alanı (🏆 büyük emoji, sarı renk)
     * Challenge açıklaması
     * Bilgi satırları:
       - ⏱ Kalan süre: X gün
       - 💎 XP Ödülü: +1200 XP
       - 🎯 Zorluk: DifficultyWeight'e göre (1.0=Kolay, 1.5=Orta, 2.0=Zor)
     * Alt: İki buton yan yana:
       - "Kapat" — ghost style, modalı kapat
       - "Düelloya Gir ⚔️" — primary style, navigate('/duel')
   - Dışarı tıklayınca kapansın (overlay onClick)
   - ESC tuşuyla kapansın (useEffect + keydown listener)

2. ChallengesCard'ı güncelle:
   - selectedChallenge state ekle (null veya challenge objesi)
   - "Katıl" butonuna: onClick={() => setSelectedChallenge(challenge)}
   - Modal'ı render et: selectedChallenge varsa göster
   - Modal kapatınca: setSelectedChallenge(null)

3. styles.css'e modal animasyonu ekle:
   .challenge-modal-overlay {
     animation: fadeIn 0.2s ease;
   }
   .challenge-modal-card {
     animation: slideUp 0.25s ease;
   }

Kurallar:
- Mevcut tasarım diline uy (glass efekti, mor tema)
- useNavigate hook'u ekle
- TypeScript değil JSX
- Başka hiçbir şeye dokunma
